## Project Objective
The objective of this project is to develop a simple web application that helps students organize and manage their academic tasks and deadlines efficiently.

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
- src/ - Application source files
- tests/ - Test cases and testing files
- docs/ - Project documentation
- README.md - Project information and setup instructions

## Setup Instructions
1. Download or clone the project repository.
2. Open the StudentTaskManagement folder in VS Code.
3. Open src/index.html in a web browser to view the application.
